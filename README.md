# NutriMind AI – Context-Aware Food Assistant

## 📌 Vertical

Food & Health Assistant

## 🧠 Overview

NutriMind AI is a smart, context-aware assistant that helps users make healthier food choices by analyzing their eating habits, goals, and situational context such as time and mood.

## ⚙️ Approach & Logic

The system uses a structured prompt to simulate an intelligent nutrition assistant. It considers:

* Food item
* Time of day
* User goal (weight loss, muscle gain, etc.)
* Mood
* Activity level

Based on these inputs, it generates:

* Health score
* Insight
* Better food alternatives
* Actionable habit tips

## 🚀 How It Works

1. User enters food and context inputs
2. Data is passed into a structured AI prompt
3. The assistant analyzes and generates personalized output
4. Results are displayed in a clean UI

## 🔧 Google Services Used

* Google Fonts for UI design
* (Optional) Firebase for storing user interaction data

## 📊 Features

* Context-aware decision making
* Behavioral insights
* Personalized recommendations
* Clean and minimal UI

## ⚠️ Assumptions

* Nutritional scoring is heuristic-based
* Suggestions are generalized and not medical advice
